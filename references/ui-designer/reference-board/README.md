# 参考板 · 顶级个人工具

> 用途：UI Designer 开工前必须选 2–3 个参考，读真实产品界面，写出「学什么 / 不学什么」。
> 参考图在 `images/`，全部是 App Store 截图中**产品界面本体**（设备框外的营销文案不算证据）。

---

## 0. 使用规则

1. **看产品层，不看营销层**：设备框内的 UI 是证据；框外的标题、奖项、渐变背景不是。
2. **抄结构，抄工艺参数；不抄品牌资产**：构图、密度、字阶、状态处理、组件组合可以学；logo、专属插画、商标、逐像素复刻不碰。
3. **至少一个参考来自不同品类**：防止只在一个品类里均值化。
4. **参考板必须落地成表**：每个参考写「学什么 / 不学什么 / 用在哪一屏」。
5. **参考不是拼贴**：最终只能有一个视觉方向；参考是采样来源，不是设计本身。

## 2. 从参考中提炼的视觉语法

### 2.1 构图（每屏至少一种，不能全是垂直堆叠）

| 构图 | 适合 | 参考 |
|---|---|---|
| **圆环网格** | 每日打卡、多习惯总览 | Streaks |
| **时间轴** | 一天中的习惯顺序、routine | Structured |
| **卡片流** | 习惯详情、进度与动作 | Habitify |
| **统计仪表** | 周/月回顾、连续天数 | Streaks 统计页 |
| **侧栏 + 详情** | 桌面端、多习惯管理 | Things 3 / Bear |

### 2.2 排版

- 一个**大数字**做视觉锚点（连续天数 / 完成率 / 本周次数），字号至少是正文的 3 倍。
- 标题与正文的层级靠**字号 + 字重 + 字距**，不靠色块。
- 个人工具可以有**一个 serif 角色**（标题或数字），但正文保持无衬线；serif 是温度，不是装饰。
- 数字用 `tabular-nums`；日期与时间用等宽或表格数字。
- 一屏最多两个字号层级同时抢注意力。

### 2.3 色彩

- **一个主强调色 + 一个语义色系统**；习惯图标可以用 4–6 个低饱和色，但界面 chrome 只用中性色。
- 背景不用纯白：暖纸白 / 冷纸白 / 暗色画布三选一，并给暗色映射。
- 每个习惯一个色，但**同一屏不超过 3 个高饱和色**；颜色是身份标签，不是装饰。
- 完成态用「填充 + 对勾 + 数字」三重编码，不只靠颜色（色盲友好）。

### 2.4 组件库存（个人工具的常见件）

| 组件 | 关键状态 |
|---|---|
| 习惯圆环 / 进度环 | 未开始 / 进行中 / 完成 / 连续 / 中断 / 冻结 |
| 打卡按钮 | 默认 / 按下 / 完成 / 撤销 / 禁用 / 加载 |
| 连续天数 chip | 当前 / 最佳 / 即将中断 / 已中断 |
| 日历热力图 | 有数据 / 无数据 / 未来 / 今天 / 补记 |
| 统计卡 | 大数字 / 趋势 / 对比 / 空数据 |
| 习惯卡片 | 默认 / 完成 / 跳过 / 编辑 / 归档 |
| 空状态 | 首次 / 全部完成 / 无数据 / 错误 |
| 庆祝时刻 | 达成 / 连续里程碑 / 周回顾 |

### 2.5 动效（仅反馈与庆祝）

- 打卡：圆环填充 200–300ms，对勾 150ms，轻微 scale 不超过 1.05。
- 连续里程碑：一次性庆祝，不循环；用户可关闭。
- 禁止：装饰性漂浮、无限循环渐变、视差。

## 3. 视觉表现力门（交付前逐条）

- [ ] 每个核心屏至少一个**视觉锚点**：圆环 / 大数字 / 图表 / 真实图标系统 / 图像卡片。
- [ ] 至少一屏的构图不是「标题 + 列表 + 分隔线」的垂直堆叠。
- [ ] 有明确的**排版签名**：字阶、字重、字距、字体配对至少一项是主动选择，不是默认。
- [ ] 有**真实资产**：统一图标系统（Lucide / Phosphor / SF Symbols 风格）或真实图像；没有 emoji 当图标。
- [ ] 完成态是**多重编码**（形状 + 颜色 + 文字/数字），不只靠颜色。
- [ ] 空状态有引导行动，不是「暂无数据」。
- [ ] 暗色映射不是简单反色；有独立的表面层级与对比度。
- [ ] 5 秒 squint：能认出这是「习惯工具」，不是通用待办模板。

## 4. 反例（这轮做饭 case 的失败）

`product-studio-evals/ui-designer-case-01/` 是一份真实失败样本：

- 令牌系统认真（OKLCH、暖灰、柿子橙、三层结构），但界面是**纯文字列表 + 分隔线 + 一个按钮**。
- 没有参考板，没有视觉锚点，没有图标系统，没有数据可视化。
- 密度按 B2B 工具做，把消费型产品做成了笔记应用。

**结论：只有纪律、没有参考板和视觉资产，产出就是「带令牌的线框」。**

# UI Designer · 反模式

> 这 17 个模式是 UI Designer 最容易犯的错。交付前逐条对照。
> 来源：A6 审美层研究（2026-08-14）+ 产品 UI 组件规则 + 能力包案例观察。

---

## 1. AI slop 四件套

**长什么样**：
> 紫色渐变 hero、emoji 当标题、四张等宽等高卡片、所有元素 16px 圆角 + 同一种阴影。

**为什么有害**：这是模型从训练分布里采到的最可能值；用户一眼认出「AI 生成的」，信任度直接下降。

**怎么避免**：四项 slop-tell 逐项检查（渐变滥用 / Inter 默认参数状态 / 统一卡片网格 / 统一圆角阴影堆叠）；三改动地板至少做三样（主色、圆角家族、字体配对）；5 秒 squint 快照不能指纹化为 shadcn / Tailwind 默认。

---

## 2. 用营销层的空间值做产品 UI

**长什么样**：
> 参考 Raycast 官网的 86px pill 按钮、64px display 标题、spacious 留白，直接用到产品首屏。

**为什么有害**：营销面与产品面的空间语域可以系统性相反。Raycast 公开页 spacious/rounded，产品层 tight/compact/sharp——照搬抽取值是把两个系统混在一起。

**怎么避免**：来源过滤门——每个规格区块打 `marketing|product|docs|brand-identity` 标签；营销层的 spacing / radius / shadow / density / display 字号一律丢弃，不缩放；色彩与字体族可跨层。

---

## 3. 页面里发明值

**长什么样**：
> 令牌表定了 12px 卡片圆角，页面里又出现 `border-radius: 14px`、`#1A1A1A`、`padding: 20px`。

**为什么有害**：系统开始漂移；下一屏会出现 18px 和 22px；改密度时改不动；执行纪律从第一个裸值开始崩塌。

**怎么避免**：页面里零裸 hex / 裸 px；所有值引用令牌；新增值先进令牌表再使用。

---

## 4. 状态当清单

**长什么样**：
> 「状态：默认、悬停、聚焦、禁用、加载、错误、空。✅ 完成。」

**为什么有害**：只打了勾，没有设计每个状态用户看到什么、能做什么；加载是白屏，错误是「出错了」，空是「暂无数据」。

**怎么避免**：每个状态写「看到什么 + 能做什么」；空状态引导行动；错误就地恢复；异步动作必须有 loading + disabled + 标签切换。**关键状态必须有实际屏幕或状态页**——只在规格里写「已覆盖」不算覆盖。

---

## 5. 只有快乐路径

**长什么样**：
> 用户打开 → 选择 → 完成。没有空、错、离开-回来、放弃、成长、极端。

**为什么有害**：真实用户会犯错、会离开、会放弃；只设计快乐路径等于没设计。

**怎么避免**：核心界面逐一对照空 / 错 / 加载 / 极端数据 / 离线 / 权限不足；每个流至少覆盖 6 条非快乐路径。

---

## 6. 空状态「暂无数据」

**长什么样**：
> 一个灰色图标 + 「暂无数据」。

**为什么有害**：空状态是用户第一次见到产品的地方，也是最低成本的教学位置；「暂无数据」浪费了它。

**怎么避免**：首次使用 → 场景说明 + 行动按钮；无结果 → 说明为什么空 + 下一步；错误导致 → 错误说明 + 重试。文案具体，不泛化。

---

## 7. 用「高级感」代替具体决策

**长什么样**：
> 「整体追求高级感、呼吸感、氛围感，让用户感到舒适。」

**为什么有害**：每一句都正确，但每一句都不能指导任何具体决策；下游无法评审，也无法复现。

**怎么避免**：每个形容词换成一个可观察的参数：温度 → 灰阶色相与圆角；呼吸感 → 段间距与行长；克制 → 强调色配给与字重上限。

---

## 8. 假装 AI 能判断美

**长什么样**：
> 「我认为这套设计已经达到顶级产品 UI 水准，审美上没有问题。」

**为什么有害**：把审美判断标成 ✅，下游会把假设当事实；签名层（字体选型、品牌图形）被越权决定。

**怎么避免**：区分「可自动检查」（对比度、令牌、状态覆盖、slop-tell）与「需人眼」（温度、字体配对、动效时序、签名层）；后四项标 ⚠️/🔮；人类检查点写成 3 变量 × ≤5 屏。

---

## 9. 只锚定颜色凑数

**长什么样**：
> 8 轴里有 7 轴全默认，只把主色从蓝换成橙，然后声称「已经做了差异化」。

**为什么有害**：色彩轴是差异最小的子空间；「门被形式满足，实质绕过」——快照仍然像模板。

**怎么避免**：≥5/8 轴携带论证过的非默认值；每轴写取值、论证、置信度；至少包含一根排版轴和一根结构轴。

---

## 10. 抄参考系统的皮

**长什么样**：
> 「参考 Linear，所以用深色背景 + 紫色强调 + 细边框。」

**为什么有害**：学到的是皮，不是结构；Linear 的核心是令牌纪律、状态覆盖、配给政策，不是深色紫。

**怎么避免**：每个参考写「学什么 / 不学什么 / 证据来自产品层还是营销层」；至少一个参考来自不同品类。

---

## 11. 圆角与阴影失控

**长什么样**：
> 卡片 16px 圆角 + 0 4px 16px 阴影 + 1px 边框 + 背景色；按钮 12px 圆角 + 另一套阴影；每个元素都浮起来。

**为什么有害**：视觉噪音；层级失效——所有东西都突出，等于没有东西突出；这也是 slop 的签名之一。

**怎么避免**：按信息层级选一种分隔方式（间距 / 背景 / 边框 / 阴影之一）；高程用语境匹配的工程化阴影，不用统一大阴影；同一系统内圆角家族不混屏。

---

## 12. 工艺先于状态

**长什么样**：
> 首屏打磨到像素级，但主按钮没有 loading、表单没有错误态、列表没有空状态。

**为什么有害**：品质判断先在第一眼形成，但产品要在使用中活下去；状态缺失是真实的 affordance 谎言，会导致双击重复提交、用户卡死。

**怎么避免**：顺序铁律：状态覆盖在工艺之前；快照与状态两门通过后才投资字体配对、中性色暖度、动效时序。

---

## 13. 交接没有「大胆 / 退路 / 等验证」

**长什么样**：
> 把设计稿和设计系统一丢：「请查收。」

**为什么有害**：Critic 不知道重点看什么；Prototype 不知道哪些结构已验证；下游可能把 🔮 当 ✅ 做完整设计。

**怎么避免**：交接时明确四件事——重点设计了什么、没设计什么、哪些 ✅ 大胆、哪些 🔮 留退路、哪些等验证结果。

---

## 14. 把设计件当生产代码交付

**长什么样**：
> 交付 HTML 时附带 React 组件、状态管理、API 调用、构建配置。

**为什么有害**：超出 UI Designer 的边界；设计件混杂工程实现后，评审对象变得不可控；「不做开发」是 Studio 的硬约束。

**怎么避免**：HTML/CSS 只作为设计件与可点击原型，用于设计验证；不产出生产代码、后端、部署；可点击原型明确标注「非生产代码」。

---

## 15. 纯文字堆叠

**长什么样**：
> 标题 + 一条说明 + 列表 + 分隔线 + 一个按钮；整屏没有一个圆环、图表、大数字或图标系统。

**为什么有害**：这是文档，不是产品。用户看不到进度，只读到状态；没有视觉锚点，就没有「想打开」的理由。

**怎么避免**：每个核心屏至少一个视觉锚点——圆环 / 大数字 / 图表 / 图像卡片 / 统一图标系统；至少一屏构图不是垂直堆叠。

---

## 16. 没有参考板，凭文字想象

**长什么样**：
> 「参考 Linear，所以深色背景 + 紫色强调 + 细边框。」没有截图、没有拆解、没有「不学什么」。

**为什么有害**：文字记忆只能留下最表面的标签；结果既不像参考，也没有自己的方向，落到训练分布的均值。

**怎么避免**：开工前抓 2–3 个真实产品界面截图，写成 `reference-board.md`：学什么 / 不学什么 / 用在哪一屏；参考是采样来源，不是拼贴。

---

## 17. 把个人工具做成企业后台

**长什么样**：
> 顶部工具栏 + 左侧导航 + 数据表格 + 筛选器 + 分页；密度 8–9；没有任何庆祝时刻或温度。

**为什么有害**：个人工具每天被打开，需要的是「愿意回来」；企业后台的效率语言会把它变成另一个待办负担。

**怎么避免**：一屏只做一件事；密度 4–6；有数据可视化与庆祝时刻；文案有温度但不甜腻；工具型纪律（令牌 / 状态 / 对比度 / 焦点）保留。

## 交付前自检

- [ ] 有参考板吗？每个参考写了学什么 / 不学什么 / 用在哪一屏吗？

- [ ] 有没有用 emoji 当图标？图标系统风格统一吗？
- [ ] 四项 slop-tell 都避开了吗？三改动地板做了几样？
- [ ] 每个关键决策能追到赌注 / IA / 场景吗？
- [ ] ≥5/8 轴有论证过的非默认值吗？
- [ ] 页面里有裸 hex / 裸 px 吗？
- [ ] 核心组件 ≥5 态？核心界面覆盖空 / 错 / 加载 / 极端？
- [ ] 空状态引导行动、错误就地恢复？
- [ ] 密度是产品 UI，不是营销页？
- [ ] 对比度 / 触控目标 / 焦点 / 行长达标？

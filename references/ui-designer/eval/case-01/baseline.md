# Baseline · UI Designer Eval Case 01（个人习惯工具）

> 一个**没有参考板、没有视觉表现力门**的通用 Agent 通常会产出什么。评分时先读这个。

## 典型产出

1. **视觉方向**：「温暖、友好、极简」；紫色渐变背景 + 白色圆角卡片。
2. **布局**：顶部大标题「我的习惯」+ 四张等宽卡片（今日打卡 / 连续天数 / 本周完成 / 成就），下面一条习惯列表，行与行用分割线。
3. **导航**：5 个底部 Tab（首页 / 习惯 / 统计 / 发现 / 我的），文字 + emoji 图标。
4. **令牌**：有颜色 / 字号表，但页面里仍有裸 hex 和临时 px。
5. **组件**：按钮只有 default / hover；卡片全是 16px 圆角 + 同一阴影；打卡只有一个圆形按钮，没有三级完成度。
6. **状态**：「默认、悬停、点击、禁用」4 个，打勾即完成；中断显示红色「已中断 3 天」。
7. **空状态**：「暂无习惯，点击添加」。
8. **统计**：三个大数字 + 一句「继续加油」；没有图表。
9. **设计理由**：「采用温暖配色和圆角卡片，营造舒适、积极的习惯养成体验。」
10. **置信度**：全部 ⚠️，或没有标注。
11. **交接**：只交设计稿，没有参考板、没有哪些是假设、没有待验证。

## 它缺什么

- 没有参考板，没有真实产品界面作为采样来源。
- 没有视觉锚点：纯文字 + 分割线 + 通用卡片；首屏不像一个「想打开」的产品。
- 没有数据可视化：统计页只有数字，没有圆环 / 折线 / 热力图。
- 没有图标系统：emoji 当图标，风格不统一。
- 打卡反馈制造羞耻：红色中断、连续天数归零。
- 没有三级完成度，退行路径不存在。
- 没有体感记录，回顾页没有「身体变化」。
- 密度是企业后台的，不是个人工具的。
- 审美判断全部标 ✅，没有人类检查点。
- 交接没有「哪些大胆 / 哪些退路 / 哪些等验证」。

## 评分提示

如果产出和 baseline 的差别只有「颜色更暖、卡片更圆、文案更温柔」，以上缺项仍在 → 能力包没有生效。

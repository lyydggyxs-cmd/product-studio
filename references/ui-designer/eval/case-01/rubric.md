# Case Rubric · UI Designer Eval Case 01（个人习惯工具）

> 先按 `references/ui-designer/rubric.md` 打 8 维分；再用下面的 case-specific 检查。
> 视觉表现力门独立于 32 分，pass/fail。

## Case-specific 检查

| # | 检查项 | 通过标准 | 证据位置 |
|---|---|---|---|
| 1 | **参考板成立** | 2–3 个参考；每个写学什么/不学什么/用在哪一屏；至少一个不同品类；产出能看到参考的结构影响 | |
| 2 | **视觉锚点** | 每个核心屏至少一个圆环/大数字/图表/图像卡片/图标系统；没有纯文字堆叠 | |
| 3 | **构图多样** | ≥2 屏使用不同构图（圆环网格 / 统计仪表 / 时间轴 / 卡片流 / 侧栏+详情）；不是所有屏垂直堆叠 | |
| 4 | **数据可视化** | 回顾页有一个真正的图表（圆环/折线/柱状/热力图），不是只有数字 | |
| 5 | **图标系统** | 统一 stroke / 尺寸 / 风格；没有 emoji 当图标 | |
| 6 | **打卡与完成态** | 完整/简化/微型三级视觉平等；完成态多重编码（填充+对勾+数字）；中断不红色警报 | |
| 7 | **状态覆盖** | 核心组件 ≥5 态；今天屏覆盖默认/完成/空/中断后/加载/错误/离线；空状态引导行动 | |
| 8 | **信心诚实 + 交接** | 可自动检查与需人眼分开；审美判断标 ⚠️/🔮；交接有大胆/退路/等验证 | |

## 常见失败

- 没有参考板，或参考板只是「参考 Linear，所以深色紫」。
- 首屏是「标题 + 习惯列表 + 分割线」，没有任何视觉锚点。
- 统计页只有三个大数字 + 「继续加油」，没有图表。
- emoji 当图标；图标风格混用。
- 打卡只有「完成 / 未完成」，没有三级退行路径。
- 中断显示红色「已中断 3 天」或连续天数归零。
- 所有屏都是同一种垂直堆叠。
- 密度是企业后台的，不是个人工具的。
- 审美判断全部标 ✅，没有人类检查点。
- 交付 React 生产代码。

# Validation Researcher · 评分标准

> 用于评审 Validation Researcher 的产出，或用于 eval。
> 0–4 锚点；不是打分游戏，是诊断工具。

---

## 评分维度

| # | 维度 | 核心问题 |
|---|---|---|
| 1 | **验证问题** | 这轮回答哪个赌注/假设？1–3 个，还是什么都想问？ |
| 2 | **判定线先于数据** | 支持/挑战/停止/需要更多数据，是先写的吗？ |
| 3 | **方法匹配** | 任务测试/访谈/Tree test/A-B/日记，选对了吗？ |
| 4 | **任务与主持** | 任务场景化吗？主持人不引导吗？ |
| 5 | **行为证据与频率** | ≥70% 发现基于行为吗？≥3/5 才是模式吗？ |
| 6 | **价值/可用性/结构分流** | 问题类型分对了吗？路由正确吗？ |
| 7 | **小样本诚实与偏差** | n=3–5 的边界写了吗？偏差、无法判断、模拟数据声明了吗？ |
| 8 | **报告与总判断** | 有信号卡、证据、kill/pivot、明确结论吗？ |

---

## 0–4 锚点

| 分 | 含义 | 通用表现 |
|---|---|---|
| **0** | 缺失 | 完全没有这个维度 |
| **1** | 提名 | 提到概念，但没有执行 |
| **2** | 部分 | 有执行，但明显不足 / 不一致 |
| **3** | 合格 | 达到标准，可用于决策 |
| **4** | 示范 | 不仅达标，还能作为模板 |

### 1. 验证问题

| 分 | 表现 |
|---|---|
| 0 | 没有验证问题，直接报告观察 |
| 1 | 10 个问题，没有重点 |
| 2 | 有问题，但与赌注/kill 信号脱节 |
| 3 | 1–3 个问题，追到赌注/成功/kill 信号；写清支持/反驳/需更多数据 |
| 4 | 还说明了「为什么这个问题最不确定、最影响决策」 |

### 2. 判定线先于数据

| 分 | 表现 |
|---|---|
| 0 | 没有判定线，结果出来再说 |
| 1 | 只有「支持」，没有挑战/停止 |
| 2 | 有判定线，但模糊/不可观察/事后补 |
| 3 | 收数据前写死支持/挑战/停止/需要更多数据；可观察、有阈值、有分母 |
| 4 | 还给每条判定线配了观察方法；结果出来后没有改线 |

### 3. 方法匹配

| 分 | 表现 |
|---|---|
| 0 | 方法与问题不匹配（用问卷测可用性） |
| 1 | 只用了访谈，什么都问 |
| 2 | 方法大体匹配，但缺对照/任务/观察点 |
| 3 | 问题类型（可用性/价值/结构/纵向）与方法匹配 |
| 4 | 还说明了「为什么不用更强的方法」以及方法的局限 |

### 4. 任务与主持

| 分 | 表现 |
|---|---|
| 0 | 没有任务脚本 |
| 1 | 操作指令（「点击按钮」）或引导性提问 |
| 2 | 有场景，但追问仍引导；主持人纪律不清 |
| 3 | 任务场景化；追问中性；等待 ≥5 秒；不解释/不辩护 |
| 4 | 还有热身、观察点、回放原话、收尾说明；脚本可直接执行 |

### 5. 行为证据与频率

| 分 | 表现 |
|---|---|
| 0 | 全是「用户说喜欢」 |
| 1 | 少量行为，但结论基于言语 |
| 2 | 有行为证据，但模式/个案不分 |
| 3 | ≥70% 发现基于行为；≥3/5 才叫模式；1–2 人是个案；正反都报 |
| 4 | 还区分自发原话 vs 追问带出；言语/行为不一致时按行为判并解释 |

### 6. 价值/可用性/结构分流

| 分 | 表现 |
|---|---|
| 0 | 所有问题混在一起 |
| 1 | 只分「好/不好」 |
| 2 | 有分类，但路由错误（可用性当价值） |
| 3 | 每条发现标类型（价值/可用性/结构/交互视觉/需求不可测）；路由正确 |
| 4 | 还指出「价值问题本轮无证据，不能判」，不越界砍功能 |

### 7. 小样本诚实与偏差

| 分 | 表现 |
|---|---|
| 0 | 把 n=3 外推到「所有用户」 |
| 1 | 没有偏差声明；用「证明」 |
| 2 | 有样本说明，但缺偏差/无法判断 |
| 3 | 写明 n=3–5 的边界；样本/主持/代理/demo/顺序/社会赞许偏差；无法判断项 |
| 4 | 还写「如果前提错了，结论怎么翻转」；模拟数据明确声明 |

### 8. 报告与总判断

| 分 | 表现 |
|---|---|
| 0 | 没有报告 |
| 1 | 一堆观察，没有结论 |
| 2 | 有结论，但缺证据/路由/迭代建议 |
| 3 | 信号卡 + 问题→结果→证据 + 模式/个案 + 类型 + 路由 + 总判断 |
| 4 | 还区分紧急/下版/探索；kill/pivot 信号明确；下游可直接行动 |

---

## 门控规则

以下任意一条触发，**退回重做**：

- **维度 1 = 0**：没有验证问题 → 这不是验证，是观察日记。
- **维度 2 = 0**：没有预注册判定线 → 结果无法判定，事后解释。
- **维度 5 ≤ 1**：全是言语/没有模式区分 → 不能作为产品证据。
- **维度 7 = 0**：没有小样本边界/偏差声明，或把模拟数据当真人 → 结论不可信。

## 总分参考

| 总分（8 维，满分 32） | 判断 |
|---|---|
| 28–32 | 可作为模板 |
| 22–27 | 可进入下游 |
| 16–21 | 需修正后重审 |
| < 16 | 退回 |

> 总分只作参考；门控优先。

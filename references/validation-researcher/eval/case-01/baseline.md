# Baseline · Validation Researcher Eval Case 01（个人习惯工具）

> 一个**没有能力包**的通用 Agent 通常会产出什么报告。评分时先读这个。

## 典型产出

1. **没有验证问题**：直接汇总「5 个用户的使用情况」。
2. **没有预注册判定线**：结果出来后才说「4/5 选非完整档，说明成功」。
3. **把选择当合法性**：4/5 选了简化/微型 → 直接判「用户接受三级平等」，忽略 2 人说「像没做」。
4. **频率不分**：1 人问「哪个是推荐」→ 写成「用户普遍困惑」。
5. **类型混淆**：1 人问「哪个是推荐」→ 路由 UI「加提示」，而不是结构/默认档问题。
6. **把模拟数据当真人**：写「用户 S3 说……」，不声明模拟。
7. **没有偏差声明**：n=5、模拟、单主持人；却写「证明用户接受」。
8. **只报支持**：隐藏 2 人说「像没做」、1 人说「只完成三分之一」。
9. **总判断模糊**：「整体反馈积极，建议继续优化。」
10. **给方案**：「建议把默认档改成完整」「加一个说明」。

## 它缺什么

- 没有验证问题与预注册判定线。
- 没有行为/言语区分；没有模式/个案区分。
- 没有价值/可用性/结构分流；路由错误。
- 没有模拟数据声明与偏差声明。
- 只报支持假设的发现；总判断没有证据支撑。
- 给方案；越界做产品决策。

## 评分提示

如果产出和 baseline 的差别只有「格式更专业、有表格」，但缺少预注册、频率、类型、偏差、模拟声明或明确总判断，以上缺项仍在 → 能力包没有生效。

# IA & Flows · 个人习惯工具（Eval Case 01）

> 来自 Product Architect。结构服务于 B1 赌注：不制造羞耻感、保留微小行动、回看体感。
> 注意：大部分节点是 ⚠️/🔮，不是 ✅。

## 1. 竞争性结构假说

| 假说 | 组织方式 | 依据 | 最优场景 | 失效场景 |
|---|---|---|---|---|
| A 今天优先 | 今天 / 习惯 / 回顾 / 我 | 用户每天只关心「现在做什么」 | 日常打卡 | 想管理多个习惯时入口深 |
| B 习惯优先 | 习惯列表 / 详情 / 今天 / 回顾 | 用户想按习惯管理 | 多习惯用户 | 每天多一步才能打卡 |
| C 时间轴优先 | 今天的时间轴 / 周 / 月 / 设置 | Structured 式的一天 | 有固定 routine | 习惯不按时间排列时失效 |

**当前选择**：A（今天优先），B 作为二级结构。
**最危险替代**：B——如果用户其实想先看「我有哪几个习惯」，今天优先会让他们找不到管理入口。
**区分性证据**：首次打开时用户第一句话是「今天做什么」还是「我有哪些习惯」。

## 2. 骨架 IA

```
今天
├── 今日锚点（时间/情绪/社会/认知）
├── 主习惯卡（完整 / 简化 / 微型）
├── 打卡
└── 体感一句话（可跳过）

习惯
├── 习惯列表
├── 习惯详情（锚点 / 三级阶梯 / 历史）
└── 新增习惯

回顾
├── 本周概览（阶段感知）
├── 体感高光
└── 身份阶段

我
├── 设置
├── 数据导出
└── 关于
```

一级 4 个（≤5）；二级 ≤4；深度 3。

## 3. 用户流

### J1 · 每日打卡

```
起点：早上/晚上，用户打开产品
→ 今天屏：显示今日锚点 + 主习惯卡（完整/简化/微型三选一）
→ 决策点：做哪个版本？（3 个选项）
→ 操作：点完成
→ 体感：选一个词或跳过（1 次点击）
→ 完成：圆环填充 + 对勾 + 数字
→ 错误恢复：网络失败 → 本地记录，稍后同步
→ 改主意：可以撤销完成
→ 非快乐路径：空（第一次）/ 已中断（昨天没做）/ 离线 / 极端（累计第 30 次记录）
```

### J2 · 中断后回归

```
起点：昨天没做，用户再次打开
→ 今天屏：不显示红叉；显示「昨天没有记录。今天从微型版开始，也算数。」
→ 决策点：微型版 / 简化版 / 完整版（3 个）
→ 操作：完成
→ 完成：记录「回归」，不重置累计；显示「回来了」而不是「中断 1 天」
→ 改主意：可以补记昨天，但补记不改变「回归」叙事
```

### J3 · 周回顾

```
起点：周日晚上，用户想看这一周
→ 回顾屏：本周完成率 + 阶段感知标签
→ 数据可视化：圆环/折线/柱状任选其一为主
→ 体感高光：展示用户自己写过的一句话
→ 身份阶段：trying / exploring / fusing（用行为描述，不用内部术语）
→ 下一步：下周想试什么（可选）
```

### J4 · 新增习惯

```
起点：习惯屏 → 新增
→ 选习惯类型（健康/学习/工作/关系/其他）
→ 选锚点类型（时间/情绪/社会/认知）
→ 设三级阶梯（完整/简化/微型）
→ 设提醒（可选）
→ 保存
```

## 4. 状态矩阵（核心界面）

| 界面 | 默认 | 空 | 加载 | 错误 | 中断后 | 完成 | 离线 | 极端 |
|---|---|---|---|---|---|---|---|---|
| 今天 | 今日锚点+习惯卡 | 第一次：邀请建第一个习惯 | 骨架屏 | 本地保存失败：重试/离线 | 「回来也算数」+ 微型版 | 圆环填充+对勾+数字 | 本地待同步 | 累计第 30 次：一次性反思条（不是连续天数徽章） |
| 习惯列表 | 1–3 个习惯 | 没有习惯：模板 | 骨架屏 | 读取失败：重试 | 暂停的习惯灰度显示 | 完成态标签 | — | 习惯很多：分组/折叠 |
| 习惯详情 | 锚点+阶梯+历史 | 无历史 | 骨架屏 | 保存失败 | 中断历史不标红 | 完成历史 | — | 长历史：分页/热力图 |
| 回顾 | 本周概览+图表 | 无数据：解释+下一步 | 图表骨架 | 数据加载失败 | 中断不影响图表颜色 | 有数据 | — | 12 周/全年视图 |

## 5. 信心地图

```
✅ 已验证：0 个节点
⚠️ 推断：今天优先的结构、三级行动阶梯、体感一句话、回顾页数据可视化
🔮 猜测：三级完成度视觉平等、中断不焦虑、阶段标签可理解、身份阶段可视化
```

**最危险的 ✅ 通胀点**：不要把「不制造羞耻感」当成已验证；它是 B1 的核心假设，需要试点验证。

## 6. 致命假设与回退

| # | 假设 | 验证 | 如果错了 | 回退 |
|---|---|---|---|---|
| A1 | 今天优先的结构适合 1–3 个习惯 | 首次使用观察 | 用户找不到习惯管理 | 改为习惯优先，今天作为首屏卡片 |
| A2 | 三级完成度视觉平等不降低动机 | A/B | 动机下降 | 恢复完成度差异，但保留不羞辱文案 |
| A3 | 体感一句话有用户愿意写 | 试用频率 | 跳过率高 | 改为每周一次，不占每日流程 |
| A4 | 中断不焦虑提高回归率 | 48h 回归率 | 用户放任 | 加轻量提醒，不用红色/失败语言 |
| A5 | 回顾页图表对用户有意义 | 访谈 | 只看数字 | 简化为一个大数字 + 一句话 |

## 7. 交接给 UI

- **可以大胆设计（✅）**：无。
- **有方向支持（⚠️）**：今天优先的结构、三级阶梯、体感一句话、回顾页图表。
- **要留退路（🔮）**：三级完成度视觉平等、中断不焦虑、阶段标签、身份阶段。
- **等验证**：A2、A4、A5。
- **UI 必须回答**：今天屏的视觉锚点是什么？完成态如何多重编码？中断后如何在不羞辱的前提下仍让人想回来？回顾页用什么图表？

# UI Spec · 个人习惯工具 v0.1

> 配套文件：`design-system.md`（令牌 / 组件 / 轴锚定）、`screens/`（6 屏设计件）、`design-rationale.md`（决策理由与置信度）。
> 本文是**设计件规格**，不是生产代码。HTML/CSS 只用于设计验证；交互在此定义，未写 JS。
> 数值全部引用 `screens/tokens.css`。SVG 的坐标、`d`、`stroke-dasharray` 是绘图数据（几何），不是样式令牌；样式（颜色、线宽、字号、动效）全部走 CSS 变量。

---

## 1. 全局

### 1.1 画布与断点

| 断点 | 行为 |
|---|---|
| 360–430px（主） | 单列；页面左右 20px；内容宽 280–390；`max-width: 430px` 居中 |
| ≥768px | 本轮**不做平板布局**：仍是 430px 居中列，仅加一条发丝外框。原因：IA 是移动端优先、1–3 个习惯，平板双列没有结构收益，留到验证后再做 |
| 安全区 | 底部 `env(safe-area-inset-bottom)`；tab bar 高 76 + 安全区 |

### 1.2 字体角色

| 角色 | 字体 | 用在哪 |
|---|---|---|
| 主标题 | `--font-serif`（Songti SC） | 屏标题「今天 / 这一周」、习惯名「晚读」、体感引语、空状态标题 |
| 正文 / 控件 | `--font-sans`（SF / PingFang） | 其余全部 |
| 数字 | `--font-numeric` + `tabular-nums` | 环内 1/3、81%、21 次、日期、统计、图表标签 |

字重上限 600；宋体标题 400。禁止在正文用 700+ 或全大写中文。

### 1.3 触控与焦点

- 最小触控 48px；主按钮 52、版本次 56、习惯行 64、tab 76、体感词 44（可接受，因为词是短按选择且行高有余量）。
- `:focus-visible`：2px 苔绿 + 2px offset，全站统一。
- 键盘顺序：页面标题（不可聚焦）→ 主内容第一个可操作项 → 版本组（左右箭头切换）→ 主按钮 → 其他习惯行 → 体感词 → tab bar。
- 所有可点元素必须是 `<button>` / `<a>`；卡片本身不是按钮（零 affordance 谎言）。
- tab bar 当前项 `aria-current="page"`；版本次 `role="radiogroup"` + `role="radio"` + `aria-checked`；体感词 `aria-pressed`；环 `role="img"` + 文字摘要。

### 1.4 动效

| 动作 | 规格 |
|---|---|
| 按下 | `transform: scale(0.985)` + 背景变化，120ms |
| 选择版本 | 对勾 opacity 0→1，160ms |
| 完成打卡 | 环 `stroke-dashoffset` 260ms ease-out-quart；对勾徽章 160ms；主按钮先进入 loading（≥600ms），再切完成态 |
| 页面进入 | 仅 opacity 240ms；不做位移/缩放 |
| 全部完成 | 柔光 900ms 一次性；不循环；`prefers-reduced-motion` 降 0 |
| 禁止 | bounce / elastic / 循环 / 视差 / confetti |

### 1.5 数据与离线

- 本地优先：打卡先写本机，再同步；离线不阻塞。
- 同步状态只用一个 12px 云图标 + 文案「已存在本机，联网后会同步」，不弹窗、不红色。
- 保存失败：卡片内一行错误文字 +「重试」；数据不丢；用户可以继续用。
- 一次打卡 = 一条记录（习惯、版本、日期、体感词可选）；同一习惯同一天再打卡是「改一下」，不是新增。

### 1.6 文案语气

- 用「记下 / 记录 / 留一个词」，**用户界面不出现「打卡」二字**（内部概念保留）；「打卡」在中文里自带考核感。
- 禁用词：失败、坚持、加油、自律、应该、必须、连续 N 天、中断 N 天。
  - **唯一例外**：空状态标题「小到不会失败的事」——这里「失败」描述的是**行动规模**（小到不会做不成），不是评价用户。除此之外不出现。
- 允许词：也算数、可以、回来、今天、慢慢来、到这儿。
- 句子 ≤ 18 个汉字；不使用感叹号；不用「！」「太棒了」。
- 空状态是邀请，不是报错；错误就地恢复，不返回重来。

### 1.7 导航

- 4 个一级 tab：今天 / 习惯 / 回顾 / 我。当前项墨色 + 标签下 6px 苔绿圆点（强调色作标点）。
- 无 badge、无红点、无未读数。
- 二级页（习惯详情）保留 tab bar，用左上返回；返回目标 = 习惯列表。

## 2. 今天 · 默认（`screens/01-today.html`）

**目的**：30 秒内完成一次记录，并且不让人感到被考核。

### 2.1 结构

| 区域 | 内容 | 规格 |
|---|---|---|
| 状态栏 | 时间 + 信号/wifi/电池 | 设备 chrome，不属于产品 UI；高 40 |
| 页头 | 眉题「11月17日 · 周二」/ 宋体「今天」/ 副文案 | 眉题 11/500 三级色；标题 32/400 宋体；副文案 13 次级 |
| 周条 | 最近 7 天：周字 + 日期 + 圆点 | 有记录实心、仅微型空心苔绿、无记录发丝空心；今天加 2px 墨色下划线；**不显示连续天数** |
| 主角卡 | 环 + 习惯身份 + 锚点 + 近七天 + 三级版本次 + 主按钮 | 24 圆角、20 内边距、单层柔影；卡内间距 16 |
| 今日环 | 148px、11px 描边、三等分刻痕；中心 `1/3` + 「今天」 | 苔绿进度；数字 38/600 tabular；环 `aria-label="今天完成 1 件，共 3 件"` |
| 习惯身份 | 40px 图标底 + 宋体「晚读」 | 图标 20（40px 底色）、描边 1.75；名称 24/400 |
| 锚点 | 「触发 / 洗完碗，水壶还热着」 | 11 眉题 + 13 正文；最多 2 行，超出省略 |
| 近七天 | 「5 / 7 天」 | 数字 tabular；不是连续天数 |
| 三级版本次 | 完整 20 分钟 / 简化 5 分钟 / 微型 翻开书 | 三等分、等宽等高 56、同字号；选中 = 苔绿浅底 + 1px 苔绿边 + 对勾，不加粗不放大 |
| 主按钮 | 「记下：简化版 · 5 分钟」 | 52 高、12 圆角、苔绿底纸白字；**默认预选简化**（可持续版本），不是完整 |
| 其他习惯 | 0–2 行：迷你环 24 + 名称 + 锚点 + 状态 | 行高 64；发丝线分隔；无卡片、无阴影；状态中性色 |
| 体感提示（锁） | 「记下之后，给身体留一个词」 | 卡片降为凹陷面；**不渲染词 chip**（不展示暂时不可用的选择），只保留标题 + 说明 + 叶子 |
| Tab bar | 4 项 | 76 + 安全区；激活墨色 + 苔绿点 |

### 2.2 交互

1. 打开：`简化` 已选中，按钮文案即「记下：简化版 · 5 分钟」——**一次点击完成**（J1 ≤3 次点击的目标被压到 2 次）。
2. 点其他版本：选中态移动，按钮文案同步切换（防误提交）。
3. 点主按钮：
   - 立即禁用 + 文案「正在记下…」+ 三点 loading（≥600ms，防双击）；
   - 成功：环 260ms 填充 → 对勾徽章 → 卡片切换为完成摘要 + 「改一下」；体感卡解锁；`aria-live` 播报「已记下，简化版」。
   - 失败：按钮恢复，卡底出现 `--color-error` 文字「没存上，已留在本机。重试」；数据保留。
4. 点其他习惯行：进入习惯详情（不直接打卡——避免误触；打卡只在详情或今天主角卡）。
5. 点「改一下」：回到版本次 + 主按钮；5 秒内可再次提交；不弹确认框。
6. 点体感词（解锁后）：单选，再点取消；未选时「跳过」可见，选中后底部换成「今天：X」+「写一句」；不给分、不提示。
7. 点 tab：切换一级区域；当前页保留滚动位置。

### 2.3 状态

| 状态 | 看到什么 | 能做什么 |
|---|---|---|
| 默认 | 环 1/3、简化选中、主按钮、两条支持行、体感锁定 | 换版本 / 完成 / 打开习惯 |
| 选择后 | 对勾移动、按钮文案更新 | 完成 / 换版本 |
| 提交中 | 按钮禁用 + loading + 三点；无第二个主按钮 | 等待（不可双击） |
| 已完成 | 环 3/3 + 对勾徽章 + 数字；完成摘要；体感解锁 | 改一下 / 选词 / 打开习惯 |
| 中断后 | 中性 banner + 微型预选；无红叉、无「中断 1 天」 | 完成微型 / 补记昨天 / 换版本 |
| 离线 | 顶部中性离线 banner（云图标 + 「记下会先留在本机，联网后自动同步」）+ 卡底「待同步 · 1 条」 | 照常完成 / 改一下 |
| 加载 | 页头 + 静默骨架（环、行、按钮）；tab 可用；`aria-busy` | 等待 |
| 保存失败 | 整屏状态卡「这次没记上 / 数据还在本机，没有丢」+ 重试 / 稍后再说 | 重试 / 稍后再说 |
| 无锚点（禁用） | 版本次可见但主按钮禁用；下方「先给这个习惯一个锚点」+「去设置」 | 去设置 / 返回 |
| 空（首次） | 见 `05-empty.html` | 建第一个习惯 |
| 极端（累计 30 次） | 主角卡上方一次性反思条：「第 30 次。想留一句话给开始那天吗？」 | 写一句 / 跳过；**不是连续天数徽章** |

> 加载 / 保存失败 / 离线三态已渲染在 `screens/07-states.html`。

## 3. 今天 · 完成（`screens/02-today-complete.html`）

**目的**：把「做完」收束成一个安静的时刻，而不是奖励爆炸。

- 页头副文案：「三件小事，都落了地。」
- 庆祝条：`role="status" aria-live="polite"`；「今天到这儿。」+「灯可以关了，明天见。」；900ms 一次性柔光；无 confetti、无音效、可关（关闭后只保留文案）。
- 环：3/3 全填充 + 右上对勾徽章 + 中心数字 3/3（三重编码）。
- 主角卡：版本次收起为完成摘要「今天：简化版 · 5 分钟」+ 苔绿对勾 + ghost「改一下」（撤销图标）。
- 支持行：两行都完成，迷你环全填充 + 对勾 + 「今天 · 完整 / 微型」——**微型与完整在视觉上同权**。
- 体感卡：解锁；6 个词单选；已选「松」；底部「今天：松」+ ghost「写一句」；词可取消。
- 不出现：连续天数、积分、等级、分享按钮、全屏弹窗。

## 4. 今天 · 中断回归（`screens/06-today-return.html`）

**目的**：昨天没做，今天仍愿意回来。

- 页头副文案：「昨天空了一天。今天还在。」
- 周条：昨天与今天的点是发丝空心；其他天正常；**没有红色、没有感叹号**。
- 回归条（`role="note"`）：苔绿叶图标 + 「昨天没有记录。」+「今天从微型版开始，也算数。补记昨天也可以，不改今天。」；「补记昨天」是内联文字链接（次要动作，不抢主按钮）。
- 主角卡：环仍显示今天 1/3；版本次**预选微型**；主按钮「记下：微型版 · 30 秒」。
- 支持行：中断的习惯显示「3 天前 · 微型」而不是「中断 3 天」；不降灰。
- 体感卡：保持锁定，文案「今天只要翻开书就好。词可以以后再说。」——降低当天的第二个门槛。
- 完成后的叙事：「回来了」而不是「中断结束」；补记昨天不改变今天的记录。

## 5. 回顾（`screens/03-review.html`）

**目的**：一周后回看，「我走了多远」和「身体有什么变化」；不是考核报表。

### 5.1 结构

| 区域 | 内容 | 规格 |
|---|---|---|
| 页头 | 眉题「11月11日 — 11月17日」/ 宋体「这一周」/「看看这一周，不急着评价它。」 | 32 宋体 |
| 大数字 | **81%** + 「+12%」pill + 「较上周 · 完成 17 / 21 次」 | 56/500 tabular；一屏只让这一个数字抢注意力 |
| 主图卡 | 14 日面积 + 折线；直接标注 11.04 / 11.10 / 今天；无 y 轴网格、无图例 | 18 圆角、1px 发丝、无阴影；线 2px、面积 10% 苔绿 |
| 7 日节奏 | 横向 7 根小柱 + 周字；满值实心苔绿，部分值 48% 苔绿 | 主图卡的次级信息，不单独成图 |
| 两个小统计 | 「2 次 / 回来过的次数」；「6 个词 / 身体记下的词」 | 数字 24/600；标签 12 |
| 体感高光 | 眉题「身体说过的话」+ 宋体引语 +「11 月 12 日 · 早起散步」 | 18 宋体；凹陷面 |
| 身份路径 | 3 节点：刚开始 / 有点感觉 / 已经很自然；当前节点苔绿 + 软环 | 节点 12；连接线发丝；注「这里不是等级，是一段路。」 |

### 5.2 图表规则

- 一屏最多一个主图；图表直接标注端点，不画坐标轴网格。
- 0 值不是红色：折线到基线，柱子最小高度 4px 中性色。
- 颜色不是唯一编码：线 + 面积 + 端点 + 文字摘要。
- 图表必须带可读摘要：`aria-label="过去十四天每天完成的习惯数：从每天一到三次，中间有一天为零，最近七天共有十七次完成"`。

### 5.3 状态

| 状态 | 看到什么 | 能做什么 |
|---|---|---|
| 有数据 | 81% + 14 日图 + 7 日柱 + 统计 + 高光 + 身份 | 阅读；点高光进详情 |
| 数据不足（<3 天） | 图区 3 条参考线 + 「再记两天，这条线才有意义」 | 回今天记一笔 |
| 空 | 图区替换为「这一周还没有记录。今天写一笔就够。」+ 主行动 | 去今天 |
| 加载 | 图区骨架 3 条 + 数字占位 | 等待 |
| 加载失败 | 图区一行错误 + 重试；已缓存数据继续显示 | 重试 |
| 极端（365 天） | 聚合为周粒度；横轴只标 4 个端点 | 切换周/月 |
| 部分失败 | 主图在、统计缺 → 统计卡显示「这项没加载出来」+ 重试 | 重试单项 |

## 6. 习惯详情（`screens/04-habit-detail.html`）

**目的**：让用户看到「这个习惯是什么、有哪三个版本、我走了多远、身体记住了什么」。

- 顶栏：返回 + 更多（编辑 / 暂停 / 归档；本轮只做视觉位）。
- 页头：40 图标底 + 宋体「晚读」+「每晚 · 洗完碗之后」。
- 大数字：**21 次** +「28 天里 / 从 10 月 21 日开始」——累计次数，不是连续天数；避免「28 天」被读成 streak。
- 三级阶梯：左轨时间轴 3 节点（等大、同色、无「推荐」）；每项 = 标题 + 时长 + 一句话；顺序完整 → 简化 → 微型；注「三个版本都算数。今天的环不会问你是哪一版。」
- 28 日热力图：7×4 单色苔绿 4 级；0 值 = 空心发丝格；今天 = 墨色 1.5px 环；无红色；图例「少 → 多」+「从左到右 · 今天在最后一格」。
- 身体记账：日期 + 宋体词 + 一句话；发丝线分隔；最近 3 条；「全部记录 →」。
- 状态：默认 / 无历史（「还没有记录。今天翻开书就算。」+ 回今天）/ 加载骨架 / 保存失败（行内重试）/ 暂停（顶部一条中性提示 + 恢复）/ 极端（>90 天分页或月视图）。
- 响应式：360 时热力图保持 20px 格；文案换行；不缩字号。

## 7. 空状态 · 第一次打开（`screens/05-empty.html`）

**目的**：第一次打开就降低门槛，不是「暂无数据」。

- 无 tab bar（首次创建前没有一级区域）；单一收束构图。
- 插画：168px 种子弧（未闭合的苔绿圆环 + 两片叶 + 一个点）；`aria-hidden`，不是 emoji。
- 标题：宋体 28「先放下一件 / 小到不会失败的事。」（手动断行，避免「事。」孤行）。
- 正文：「两分钟也算。它不是任务，是你想成为的那种人的一个小动作。」
- 主按钮：「选一件小事」；下方 3 个等权模板 chip：读一页 / 绕一圈 / 早一点睡。
- 页脚：「数据只留在这台设备 · 不需要账号」。
- 状态：首次 / 模板加载失败（「模板没加载出来。先自己写一件。」+ 重试）/ 离线（模板可用，创建写本地）/ 无结果（不适用）。
- 禁止：「暂无数据」、灰色占位图标、营销 hero、跳过按钮（首次没有可跳过的内容）。

## 10. 可访问性自检

- 对比度（已用 OKLCH→sRGB 计算）：正文 15.2:1、次级 8.5:1、三级 6.5:1、主按钮 6.5:1、苔绿对纸 6.12:1、错误 5.3:1、警告 4.6:1、暗色正文 15.0:1、暗色三级 5.9:1。
- 触控：主按钮 52、版本次 56、行 64、tab 76、体感词 44、返回/更多 48。
- 焦点：可见 2px 苔绿；键盘可达；radiogroup 支持左右箭头（规格）。
- 语义：`h1` 每屏一个；环 `role="img"` + 数字摘要；图标 `aria-hidden`；tab `aria-current`；完成播报 `aria-live="polite"`。
- 颜色不是唯一编码：完成 = 填充 + 对勾 + 数字/文字；热力图 = 强度 + 位置；图表 = 线 + 面积 + 端点 + 摘要。
- 减少动效：`prefers-reduced-motion` 全部 0ms，庆祝直接显示终态。
- 语言：`lang="zh-CN"`；数字 tabular；中英混排不插空格（品牌名除外）。

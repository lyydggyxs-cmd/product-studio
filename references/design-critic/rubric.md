# Design Critic · 评分标准

> 用于评审 Design Critic 的产出，或用于 eval。
> 0–4 锚点；不是打分游戏，是诊断工具。

---

## 评分维度

| # | 维度 | 核心问题 |
|---|---|---|
| 1 | **范围锁定与保真度匹配** | 评什么、不评什么、为什么，写清了吗？ |
| 2 | **意图对齐** | 是否对照 bet / IA / requirements 评，而不是凭感觉？ |
| 3 | **证据质量** | 每个发现能定位到页面/组件/状态/源码吗？ |
| 4 | **严重度分级** | 🔴/🟡/🟢/⚪ 校准吗？还是全红/全绿？ |
| 5 | **状态与覆盖** | 空/错/加载/中断/极端/响应式/可访问性查了吗？ |
| 6 | **不给方案** | 只描述问题与影响，还是替设计师改稿？ |
| 7 | **路由与边界** | 问题归属正确吗？「无法判断」诚实列出吗？ |
| 8 | **总判断** | 明确 go / 有保留 / no-go，且有证据支撑吗？ |

---

## 0–4 锚点

| 分 | 含义 | 通用表现 |
|---|---|---|
| **0** | 缺失 | 完全没有这个维度 |
| **1** | 提名 | 提到概念，但没有执行 |
| **2** | 部分 | 有执行，但明显不足 / 不一致 |
| **3** | 合格 | 达到标准，可用于决策 |
| **4** | 示范 | 不仅达标，还能作为模板 |

### 1. 范围锁定与保真度匹配

| 分 | 表现 |
|---|---|
| 0 | 没有范围，什么都评或什么都评不了 |
| 1 | 有范围，但与保真度不匹配（线框评颜色） |
| 2 | 范围大体匹配，但「不评什么」缺失 |
| 3 | 明确评审对象/保真度/评什么/不评什么/输入 |
| 4 | 还说明了「为什么这轮不评 X」以及「如果 X 走不通，怎么质疑」 |

### 2. 意图对齐

| 分 | 表现 |
|---|---|
| 0 | 不读上游，直接评界面 |
| 1 | 提到 bet/IA，但没有逐条对照 |
| 2 | 有对齐表，但只对了一部分 |
| 3 | 对照 bet / 核心 Job / 关键 AC / 品牌温度 / 密度；标 ✅/❌ |
| 4 | 还能指出「设计做对了，但 Job 本身可能不成立」的价值问题 |

### 3. 证据质量

| 分 | 表现 |
|---|---|
| 0 | 只有「我觉得」 |
| 1 | 有结论，没有位置/观察 |
| 2 | 有位置，但缺原则/影响 |
| 3 | 每个发现有位置、观察到什么、原则/场景、影响 |
| 4 | 证据可复现（截图区域/源码行/状态名），且区分事实与推断 |

### 4. 严重度分级

| 分 | 表现 |
|---|---|
| 0 | 没有分级 |
| 1 | 全部 🔴 或全部 🟢 |
| 2 | 有分级，但明显错配（偏好标 🔴） |
| 3 | 🔴/🟡/🟢/⚪ 校准；阻断能回答「不改会怎样」 |
| 4 | 还说明了分级依据，并把偏好/不确定单独归 ⚪/🟢 |

### 5. 状态与覆盖

| 分 | 表现 |
|---|---|
| 0 | 只看了默认态 |
| 1 | 只评快乐路径 |
| 2 | 覆盖空/错/加载中的 1–2 个 |
| 3 | 覆盖空/错/加载/中断/极端/响应式/可访问性，逐项标 ✅/❌ |
| 4 | 还指出版本/状态矩阵里缺失的项，并路由到正确岗位 |

### 6. 不给方案

| 分 | 表现 |
|---|---|
| 0 | 直接改稿/给具体方案 |
| 1 | 多处给方案（「改成 X」） |
| 2 | 偶尔给方案，或方案混在问题里 |
| 3 | 只描述问题与影响；方案留给设计师 |
| 4 | 还能把「方向性选项」与「评审结论」分开，标明建议不是结论 |

### 7. 路由与边界

| 分 | 表现 |
|---|---|
| 0 | 不路由，或全部丢给 UI |
| 1 | 路由错误，或越界评赌注/IA |
| 2 | 路由大体正确，但边界不清 |
| 3 | 每个发现标归属；不越界；「无法判断」诚实列出 |
| 4 | 还能区分「UI 能修」与「上游问题」，并给上游附观察而非结论 |

### 8. 总判断

| 分 | 表现 |
|---|---|
| 0 | 没有总判断 |
| 1 | 模糊（「整体不错」） |
| 2 | 有判断，但缺证据支撑 |
| 3 | 明确 go / 有保留 / no-go；列出必须修项 |
| 4 | 还分清「可进入」「必须修」「记录」「不评」，下游可直接行动 |

---

## 门控规则

以下任意一条触发，**退回重做**：

- **维度 1 = 0**：没有范围 → 评审会无限膨胀或评错维度。
- **维度 3 = 0**：没有证据 → 这是意见，不是评审。
- **维度 4 ≤ 1**：全部 🔴/全绿 → 没有优先级，下游无法行动。
- **维度 6 = 0**：给方案/改稿 → 越界替设计师做决策。

## 总分参考

| 总分（8 维，满分 32） | 判断 |
|---|---|
| 28–32 | 可作为模板 |
| 22–27 | 可进入下游 |
| 16–21 | 需修正后重审 |
| < 16 | 退回 |

> 总分只作参考；门控优先。

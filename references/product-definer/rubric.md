# Product Definer · 评分标准

> 用于评审 Product Definer 的产出，或用于 eval。
> 0–4 锚点；不是打分游戏，是诊断工具。

---

## 评分维度

| # | 维度 | 核心问题 |
|---|---|---|
| 1 | **可证伪性** | 有成功信号和 kill 信号吗？能判断赌对/赌错吗？ |
| 2 | **因果机制** | 说的是「为什么」，还是「做什么」？ |
| 3 | **证据追溯** | 赌注/范围能追溯到证据 ID 吗？反对证据列了吗？ |
| 4 | **范围纪律** | 一个赌注吗？Anti-Goals 是判断还是资源借口？ |
| 5 | **Kill 信号质量** | 可观察、先于数据、指向不同病灶吗？ |
| 6 | **Plan B 具体性** | 具体转向哪里，还是「重新思考」？ |
| 7 | **PRD 连贯性** | 新人读完知道做什么/不做什么/不确定什么吗？ |
| 8 | **决策行动性** | 决策日志有理由、替代方案、重新评估条件吗？ |

---

## 0–4 锚点

| 分 | 含义 | 通用表现 |
|---|---|---|
| **0** | 缺失 | 完全没有这个维度 |
| **1** | 提名 | 提到概念，但没有执行 |
| **2** | 部分 | 有执行，但明显不足/不一致 |
| **3** | 合格 | 达到标准，可用于决策 |
| **4** | 示范 | 不仅达标，还能作为模板 |

### 1. 可证伪性

| 分 | 表现 |
|---|---|
| 0 | 「用户会喜欢」；没有成功/失败标准 |
| 1 | 有成功标准，但没有 kill 信号 |
| 2 | 有成功/kill，但不可观察（「感觉不对」） |
| 3 | 成功/kill 都具体、可观察 |
| 4 | 还写了判定线和「需要更多数据」的第三种结果 |

### 2. 因果机制

| 分 | 表现 |
|---|---|
| 0 | 只有功能描述 |
| 1 | 有「因为」，但只是重述现象 |
| 2 | 有机制，但不可区分于其他解释 |
| 3 | 机制具体，能推出可观察的预测 |
| 4 | 还写了竞争机制和区分性证据 |

### 3. 证据追溯

| 分 | 表现 |
|---|---|
| 0 | 没有证据 ID |
| 1 | 只有支持证据，没有反对证据 |
| 2 | 有证据 ID，但关键断言仍无来源 |
| 3 | 赌注/范围/决策都有证据 ID；反对证据列出 |
| 4 | 还标了证据强度、最薄弱环节、如果证据被推翻会怎样 |

### 4. 范围纪律

| 分 | 表现 |
|---|---|
| 0 | 功能列表；10+ 个「要做」 |
| 1 | 有范围，但明显是 backlog 压缩 |
| 2 | 一个赌注，但范围里混入不服务赌注的功能 |
| 3 | 一个赌注；范围是验证赌注的最小闭环 |
| 4 | Anti-Goals 有判断、被牺牲的价值、恢复条件 |

### 5. Kill 信号质量

| 分 | 表现 |
|---|---|
| 0 | 没有 kill 信号 |
| 1 | 有 kill，但不可观察（「数据不好」） |
| 2 | 可观察，但所有 kill 指向同一个「失败」 |
| 3 | 可观察；不同 kill 指向不同病灶 |
| 4 | 还写了组合规则（K1 单独 → 修正；K1+K3 → 停止） |

### 6. Plan B 具体性

| 分 | 表现 |
|---|---|
| 0 | 没有 Plan B |
| 1 | 「重新思考」「再做调研」 |
| 2 | 有方向，但没有保留/放弃什么 |
| 3 | 具体转向 + 保留什么 |
| 4 | 还写了触发条件和「转过去之后怎么验证」 |

### 7. PRD 连贯性

| 分 | 表现 |
|---|---|
| 0 | 没有 PRD，或只有模板标题 |
| 1 | 有内容，但新人读不懂核心赌注 |
| 2 | 能读懂做什么，但不知道不做什么/不确定什么 |
| 3 | 新人能读懂：是什么、为谁、赌什么、不做什么、成功标准、不确定性 |
| 4 | 还做到一页可读、版本历史、每个断言有证据或标 🔮 |

### 8. 决策行动性

| 分 | 表现 |
|---|---|
| 0 | 没有决策记录 |
| 1 | 只记「决定了什么」 |
| 2 | 有理由，但没有替代方案/重新评估条件 |
| 3 | 决定 + 理由 + 证据 + 替代 + 重新评估条件 |
| 4 | 还标了状态（active/superseded）和推翻记录 |

---

## 门控规则

以下任意一条触发，**退回重做**：

- **维度 1 ≤ 1**：不可证伪 → 这不是赌注，是愿望。
- **维度 3 ≤ 1**：无证据追溯 → 赌注建在幻觉上。
- **维度 4 = 0**：功能列表 → 没有产品定义。

## 总分参考

| 总分（8 维，满分 32） | 判断 |
|---|---|
| 28–32 | 可作为模板 |
| 22–27 | 可进入下游 |
| 16–21 | 需修正后重审 |
| < 16 | 退回 |

> 总分只作参考；门控优先。一个 30 分但维度 1 只有 1 分的产出，仍然退回。

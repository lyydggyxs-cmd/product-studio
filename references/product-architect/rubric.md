# Product Architect · 评分标准

> 用于评审 Product Architect 的产出，或用于 eval。
> 0–4 锚点；不是打分游戏，是诊断工具。

---

## 评分维度

| # | 维度 | 核心问题 |
|---|---|---|
| 1 | **心智模型假说** | 有 2–3 种真正不同的组织方式吗？有证据吗？ |
| 2 | **标签语言** | 标签是用户的话，还是设计师的话？ |
| 3 | **结构纪律** | 一级 ≤5、深度 ≤3、核心 Job ≤3 次点击？ |
| 4 | **用户流完整** | 决策点、错误恢复、改主意、非快乐路径都有吗？ |
| 5 | **状态覆盖** | 每个一级界面 8 状态都有吗？ |
| 6 | **验证工具** | 精确到研究员明天能执行吗？ |
| 7 | **信心诚实** | 每个节点标了 ✅/⚠️/🔮 吗？有没有通胀？ |
| 8 | **追溯与交接** | 结构能追溯到赌注/需求吗？下游知道哪些能大胆设计吗？ |

---

## 0–4 锚点

| 分 | 含义 | 通用表现 |
|---|---|---|
| **0** | 缺失 | 完全没有这个维度 |
| **1** | 提名 | 提到概念，但没有执行 |
| **2** | 部分 | 有执行，但明显不足/不一致 |
| **3** | 合格 | 达到标准，可用于决策 |
| **4** | 示范 | 不仅达标，还能作为模板 |

### 1. 心智模型假说

| 分 | 表现 |
|---|---|
| 0 | 没有假说，直接画 IA |
| 1 | 只有一种 LATCH，没有竞争假说 |
| 2 | 2–3 种，但差异只是措辞，产生相同 IA |
| 3 | 2–3 种真正不同，各带用户证据，说明最优/失效场景 |
| 4 | 还写了最危险替代假说和区分性证据 |

### 2. 标签语言

| 分 | 表现 |
|---|---|
| 0 | 全是内部术语 |
| 1 | 部分用户语言，部分是设计师语言 |
| 2 | 大部分用户语言，但没有来源 |
| 3 | 标签有用户原话/竞品来源；陌生人测试通过 |
| 4 | 每个标签都有来源 ID；无来源的标 🔮 |

### 3. 结构纪律

| 分 | 表现 |
|---|---|
| 0 | IA 是无限树，没有约束 |
| 1 | 一级 >7，或深度 >4 |
| 2 | 一级 ≤5，但深度/点击超标 |
| 3 | 一级 ≤5、深度 ≤3、核心 Job ≤3 次点击 |
| 4 | 还说明了为什么是这 5 个，而不是其他 |

### 4. 用户流完整

| 分 | 表现 |
|---|---|
| 0 | 没有流 |
| 1 | 只有快乐路径 |
| 2 | 有决策点，但没有错误恢复/改主意 |
| 3 | 决策点 ≤3、错误恢复、改主意、非快乐路径 |
| 4 | 每个决策点有「为什么是这 3 个」；流能直接画线框 |

### 5. 状态覆盖

| 分 | 表现 |
|---|---|
| 0 | 没有状态 |
| 1 | 只有默认态 |
| 2 | 覆盖 4–5 个状态 |
| 3 | 每个一级界面 8 状态 |
| 4 | 空状态是引导行动，错误状态是具体恢复，不是「出错了」 |

### 6. 验证工具

| 分 | 表现 |
|---|---|
| 0 | 没有验证工具 |
| 1 | 「建议做 card sorting」 |
| 2 | 有工具名，但缺材料/成功线 |
| 3 | 材料、参与者、任务、成功线、结果→行动 |
| 4 | 还写了回退到哪一步、如何合成、如何三角验证 |

### 7. 信心诚实

| 分 | 表现 |
|---|---|
| 0 | 没有置信度 |
| 1 | 全部标 ⚠️ 或全部标 ✅ |
| 2 | 有标注，但 🔮 被写成 ✅，或合并项推导标 ✅ |
| 3 | 每个节点标 ✅/⚠️/🔮，有汇总；合并项节点标 ⚠️/🔮 |
| 4 | 还写了「哪个假设错了，回退到哪一步」 |

### 8. 追溯与交接

| 分 | 表现 |
|---|---|
| 0 | 结构无法追溯到赌注/需求 |
| 1 | 提到了赌注，但结构是通用模板 |
| 2 | 部分结构能追溯 |
| 3 | 每个一级区域能追溯到核心 Job/赌注 |
| 4 | 还给下游明确「哪些能大胆设计/哪些留退路/哪些等验证」 |

---

## 门控规则

以下任意一条触发，**退回重做**：

- **维度 1 ≤ 1**：只有一种 LATCH → 这不是架构，是直觉。
- **维度 6 = 0**：没有验证工具 → IA 是猜测，不是假设。
- **维度 7 ≤ 1**：置信度通胀 → 下游会把假设当事实。

## 总分参考

| 总分（8 维，满分 32） | 判断 |
|---|---|
| 28–32 | 可作为模板 |
| 22–27 | 可进入下游 |
| 16–21 | 需修正后重审 |
| < 16 | 退回 |

> 总分只作参考；门控优先。

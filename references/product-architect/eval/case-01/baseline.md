# Baseline · Product Architect Eval Case 01

> 一个**没有能力包**的通用 Agent 通常会画出什么。评分时先读这个，避免把「更完整的 IA 树」误判为「能力包有效」。

## 典型产出

1. **IA 树**：首页 / 食谱 / 买菜 / 做饭 / 社区 / 我的 / 设置（6 个一级）。
2. **组织方式**：Category（按菜系/品类），只有一种，没有竞争假说。
3. **标签**：食谱、食材、教程、社区、我的、设置——设计师语言。
4. **用户流**：「打开 → 选食谱 → 看步骤 → 完成」——只有快乐路径。
5. **状态**：「默认、加载、错误、空」4 个，没有悬停/聚焦/按压/禁用。
6. **验证工具**：「建议做 card sorting」——没有材料、成功线。
7. **置信度**：所有节点标 ⚠️，或没有标注。
8. **和赌注的关系**：IA 是通用食谱 App 模板，没有「一人份/份量/剩菜」的位置。

## 它缺什么

- 没有竞争性心智模型。
- 标签不是用户语言。
- 一级 6 个，超过 ≤5。
- 流只有快乐路径。
- 状态不全。
- 验证工具不可执行。
- 置信度通胀/缺失。
- IA 和「购买单位 vs 消费单位」的赌注脱节。

## 评分提示

如果产出和 baseline 的差别只有「树更深、页面更多」，以上缺项仍在 → 能力包没有生效。
如果产出在竞争假说、用户语言标签、结构纪律、剩菜/份量位置、可执行验证工具上有明显改善 → 记录具体改善项。

# Baseline · Product Architect Eval Case 02

> 一个**没有能力包**的通用 Agent 通常会画出什么。评分时先读这个，避免把「更完整的 IA 树」误判为「能力包有效」。

## 典型产出

1. **IA 树**：Dashboard / Reports / Team / Settings（4 个一级）。
2. **组织方式**：按功能模块，只有一种，没有竞争假说。
3. **标签**：仪表板、报告、团队、设置——设计师/系统语言。
4. **用户流**：「打开 Dashboard → 看报告 → 完成」——只有快乐路径。
5. **状态**：「默认、加载、错误、空」4 个。
6. **验证工具**：「建议做 card sorting」。
7. **置信度**：所有节点标 ⚠️，或没有标注。
8. **和赌注的关系**：IA 是通用报告工具模板，没有「固定阅读时刻 / 决策请求 / 行动」的位置。

## 它缺什么

- 没有竞争性心智模型。
- 标签不是用户语言。
- 只有管理者视角，没有写作者侧。
- 没有「行动」入口。
- 流只有快乐路径。
- 状态不全。
- 验证工具不可执行。
- 置信度通胀/缺失。
- IA 和「读者侧 / 行动」的赌注脱节。

## 评分提示

如果产出和 baseline 的差别只有「树更深、页面更多」，以上缺项仍在 → 能力包没有生效。
如果产出在竞争假说、用户语言标签、双边结构、行动入口、可执行验证工具上有明显改善 → 记录具体改善项。

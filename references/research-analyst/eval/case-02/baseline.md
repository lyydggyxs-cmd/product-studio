# Baseline · Eval Case 02

> 一个**没有能力包**的通用 Agent，通常会长成什么样。评分时先读这个，避免把「通用好报告」误判为「能力包有效」。

## 典型产出

1. **标题**：「团队周报现状与需求调研」
2. **结论**：员工觉得周报浪费时间；管理者希望更及时的信息；需要更自动化、更简洁的周报工具。
3. **证据**：几条行业数据（「知识工作者每周花 X 小时在沟通上」），来源模糊。
4. **竞品**：飞书文档、Notion、Geekbot 的功能对比表。
5. **建议**：做「自动聚合 + AI 摘要」。
6. **缺口**：无，或「需要更多用户调研」。

## 它缺什么

- 没有区分「写」和「读」的断裂点。
- 没有管理者视角的行为证据。
- 没有「已读 vs 行动」的定义。
- 竞品只覆盖文档/异步站会，漏表格邮件/项目管理。
- 没有反证。
- 访谈问题可能是「你觉得周报有用吗」。
- 没有「如果错了」。

## 评分提示

如果产出和 baseline 的差别只有「更长、更完整」，但以上缺项仍在 → 能力包没有生效。
如果产出在这些缺项上有明显改善 → 记录具体改善项，而不是只给一个总分。

# Research Analyst · 评分标准

> 用于评审 Research Analyst 的产出，或用于 eval。
> 0–4 锚点；不是打分游戏，是诊断工具。

---

## 评分维度

| # | 维度 | 核心问题 |
|---|---|---|
| 1 | **来源可追溯** | 每条结论能打开来源吗？ |
| 2 | **置信度校准** | ✅/⚠️/🔮 用得准吗？有没有通胀？ |
| 3 | **三角验证** | 重要结论有 ≥2 个独立来源吗？ |
| 4 | **反证** | 主动找过不支持假设的证据吗？ |
| 5 | **缺口诚实** | 信息缺口具体、有影响、有补法吗？ |
| 6 | **竞品深度** | 是战略逻辑，还是功能列表？ |
| 7 | **用户语言** | 有逐字原话和行为证据吗？ |
| 8 | **行动性** | 发现能驱动决策吗？还是一堆观察？ |

---

## 0–4 锚点

| 分 | 含义 | 通用表现 |
|---|---|---|
| **0** | 缺失 | 完全没有这个维度 |
| **1** | 提名 | 提到概念，但没有执行 |
| **2** | 部分 | 有执行，但明显不足/不一致 |
| **3** | 合格 | 达到标准，可用于决策 |
| **4** | 示范 | 不仅达标，还能作为模板 |

### 1. 来源可追溯

| 分 | 表现 |
|---|---|
| 0 | 全是裸断言，无来源 |
| 1 | 少数有来源，多数是「研究表明」 |
| 2 | 一半有来源，但来源不可打开/不具体 |
| 3 | 每条重要结论有可追溯来源（URL/文件/访谈编号） |
| 4 | 来源可追溯，且标了样本、方法、局限 |

### 2. 置信度校准

| 分 | 表现 |
|---|---|
| 0 | 没有 ✅/⚠️/🔮 |
| 1 | 有标注，但明显通胀（推断全标 ✅） |
| 2 | 大体正确，但个别单源/推断被升格 |
| 3 | ✅/⚠️/🔮 使用一致，单源标 ⚠️，推断标 🔮 |
| 4 | 校准准确，且写了「为什么是这个置信度」 |

### 3. 三角验证

| 分 | 表现 |
|---|---|
| 0 | 单源结论当事实 |
| 1 | 提到三角验证，但没做 |
| 2 | 部分结论有两个来源，但不独立（同一文章转载） |
| 3 | 重要结论 ≥2 个独立来源，或明确标单源 ⚠️ |
| 4 | 多方法/多人群交叉验证，且标了不一致处 |

### 4. 反证

| 分 | 表现 |
|---|---|
| 0 | 只找支持证据 |
| 1 | 提到「要找反证」，但没有记录 |
| 2 | 找了一点反证，但不系统 |
| 3 | 对关键假设主动搜了反证，并记录发现 |
| 4 | 反证改变了结论或排序，且写了「什么会推翻当前判断」 |

### 5. 缺口诚实

| 分 | 表现 |
|---|---|
| 0 | 没有缺口，或写「无」 |
| 1 | 缺口是泛泛的「需要更多数据」 |
| 2 | 有具体缺口，但没有影响/补法 |
| 3 | 缺口具体，写了为什么重要和最快补法 |
| 4 | 缺口按风险排序，且标了「哪个缺口不填，赌注不成立」 |

### 6. 竞品深度

| 分 | 表现 |
|---|---|
| 0 | 没有竞品 |
| 1 | 只有功能列表 |
| 2 | 有战略画布，但浅 |
| 3 | 战略画布 + 体验审计 + 结构约束 + 致命弱点 |
| 4 | 还识别了「用户什么都不做」的替代方案和不对称优势 |

### 7. 用户语言

| 分 | 表现 |
|---|---|
| 0 | 全是研究者的转述 |
| 1 | 有原话，但没有场景 |
| 2 | 有原话和场景，但样本少/偏差未标 |
| 3 | 逐字原话 + 行为 + 场景 + 样本说明 |
| 4 | 原话能区分「说的」和「做的」，且标了反例 |

### 8. 行动性

| 分 | 表现 |
|---|---|
| 0 | 一堆观察，没有决策 |
| 1 | 有结论，但不知道要做什么 |
| 2 | 有建议，但没有选项/证据 |
| 3 | 决策 × 选项 × 证据 × 建议 |
| 4 | 还给了最快验证方式和「如果错了」的影响 |

---

## 门控规则

不是平均分。以下任意一条触发，**退回重做**：

- **维度 1 ≤ 1**：来源不可追溯 → 整份产出不可信。
- **维度 2 ≤ 1**：置信度通胀 → 下游会把假设当事实。
- **维度 5 = 0**：缺口为空 → 在研究上装全能。

## 总分参考

| 总分（8 维，满分 32） | 判断 |
|---|---|
| 28–32 | 可作为模板 |
| 22–27 | 可进入下游 |
| 16–21 | 需修正后重审 |
| < 16 | 退回 |

> 总分只作参考；门控优先。一个 30 分但维度 1 只有 1 分的产出，仍然退回。

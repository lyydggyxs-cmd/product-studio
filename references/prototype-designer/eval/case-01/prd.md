# PRD · 个人习惯工具（Eval Case 01）

> 活文档 v0.1。范围是设计验证版，不是生产发布。

## 1. 问题

想养成习惯的人，常见的失败不是「不知道该做什么」，而是：
- 打卡反馈让人感到被评判（连续天数归零、红色中断、排行榜）；
- 行动门槛太高，一次没做到就放弃；
- 只记录「做没做」，不记录「做完身体感觉如何」；
- 回顾页只有数字，没有意义。

## 2. 目标用户

- 个人用户，1–3 个想养成的习惯
- 有过失败经历，对「打卡」有轻微抵触
- 不需要社交监督，也不想被游戏化绑架
- 移动端为主

## 3. 本期范围

| 区域 | 内容 | 优先级 |
|---|---|---|
| 今天 | 今天的锚点 + 一个微小行动 + 打卡 + 体感一句话 | P0 |
| 习惯 | 习惯列表、习惯详情、三级行动阶梯、锚点类型 | P0 |
| 回顾 | 阶段感知进度、完成率、体感高光、身份阶段 | P1 |
| 我 | 设置、数据导出、关于 | P2 |

## 4. 核心 Job

- J1：今天打开，3 次点击内完成一次打卡，并留下一个体感词。
- J2：某天没做到，能被允许做「微型版」，而不是看到红叉。
- J3：一周后回看，能看到「我走了多远」和「身体有什么变化」。
- J4：新增一个习惯时，能找到合适的锚点，并设定三级阶梯。

## 5. 关键约束

- 打卡不能制造羞耻感；中断不是失败。
- 三种完成度（完整/简化/微型）在视觉上平等，不用颜色区分高低。
- 阶段标签要能被普通用户理解，不能是内部术语。
- 体感记录是每日核心仪式，但可以跳过。
- 不做社交、排行榜、订阅、健康数据接入。

## 6. 当前版本

- v0.1：今天 / 习惯 / 回顾 / 我 四个区域；3 个习惯以内；本地数据。
- 待验证：三级完成度视觉平等（A2）、阶段标签可理解性（A4）、中断不焦虑（A5）。

## 7. 成功标准

5 人试点：
- 14 天回访率 ≥50%
- 打卡完成率 ≥70%
- 「没有被评判」自评 ≥4/5
- 中断后 48 小时回归率 ≥40%

## 8. Anti-goals

- 不做排行榜 / 好友 / 社区 / PK
- 不做连续天数归零 / 红色中断警报 / 「你失败了」
- 不做卡路里 / 体重 / 身材评价
- 不做付费墙 / 订阅 / 增长裂变
- 不做企业 / 团队 / 多用户

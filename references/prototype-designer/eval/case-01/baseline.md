# Baseline · Prototype Designer Eval Case 01（个人习惯工具）

> 一个**没有能力包**的通用 Agent 通常会产出什么。评分时先读这个。

## 典型产出

1. **直接做完整 App**：今天 / 习惯 / 回顾 / 我 四个页面，每页都有完整视觉。
2. **没有检验问题**：不说这轮回答哪个假设，只说「做了一个习惯追踪 App 的原型」。
3. **没有支持/反驳标准**：不写观察到什么算成功/失败；做完直接说「看起来不错」。
4. **保真度错配**：用高保真、带渐变和插画的界面去测「用户需不需要三级完成度」。
5. **探索只有一个方向**：即使画了多个，也只是换色/换圆角。
6. **Lorem Ipsum / 假数据**：习惯名「习惯 1 / 习惯 2」，文案「这是一段说明」。
7. **只有快乐路径**：默认态 + 一个空状态；没有错误/离线/中断后/极端。
8. **没有学习日志**：只交原型，没有做前以为 / 做后发现 / 如果全错。
9. **没有回灌**：发现 IA 入口问题也沉默。
10. **把原型当成品**：说「这个原型已经可以上线了」或附生产代码。

## 它缺什么

- 没有「一个问题」的约束。
- 没有先写的支持/反驳标准。
- 保真度超过问题需要，反馈被视觉污染。
- 没有真实内容和非快乐路径。
- 没有学习日志，下一轮不知道改哪里。
- 没有回灌信号，上游问题被掩盖。
- 没有说「这个原型测不了什么」。

## 评分提示

如果产出和 baseline 的差别只有「页面更少、颜色更灰、文案更真实」，但缺少检验问题、支持/反驳标准、学习日志和回灌，以上缺项仍在 → 能力包没有生效。
